Contributing to OpenPromptKit

Thank you for your interest in contributing to OpenPromptKit.

OpenPromptKit is an open-source toolkit designed to help developers create structured, reusable, testable, and version-controlled AI prompts and workflows.

How to contribute

1. Fork the repository.
2. Create a new branch for your contribution.
3. Make your changes.
4. Add or update tests when appropriate.
5. Update documentation when necessary.
6. Open a pull request describing your changes.

Development principles

We value:

* Clear and maintainable code
* Practical documentation
* Reproducible examples
* Backward compatibility
* Tests for important functionality
* Small and focused pull requests

Reporting issues

Please use GitHub Issues to report bugs, request features, or suggest improvements.

Pull requests

Pull requests should explain:

* What was changed
* Why the change was necessary
* How it was tested
* Any relevant compatibility considerations

Thank you for helping improve OpenPromptKit.
